# Thrifted Tease V2 Visual System

## Purpose
This document turns the V2 visual direction into practical design guidance for layout, typography, color, interface behavior, and art direction.

## Current Visual Assessment
The existing system is coherent, but it currently reads as generic premium styling before it reads as Thrifted Tease.

The main causes are:
- navy and gold dominance
- safe system fonts
- repeated rounded CTAs
- repeated card modules with similar spacing and hierarchy

## V2 Visual Goal
Build a site that feels collected, editorial, warm, and slightly mysterious without becoming cluttered or costume-like.

## Color Direction

### What to keep from V1
- strong dark grounding
- enough contrast for readability
- disciplined restraint instead of rainbow branding

### What to change
- move away from pure premium navy-and-gold signaling
- introduce more organic, worn-in, ownable color relationships
- use accent color strategically rather than everywhere

### Palette qualities
The palette should feel:
- faded but intentional
- earthy
- tactile
- confident
- recognizably "the band" within a few screens

### Working palette roles
- deep ink or midnight as the main dark
- parchment or cream as the primary light
- muted forest, oxidized teal, or dusty blue as a secondary atmospheric tone
- rust, tobacco, or brown-red as the warm accent
- one high-contrast highlight used sparingly for emphasis

## Typography Direction

### Problem in V1
The current type is readable, but too default to carry identity.

### V2 approach
Use a deliberate pairing:
- headline type with editorial or romantic character
- body type with strong readability and calmer rhythm

### Type behavior goals
- headlines should help shape mood, not just hierarchy
- body copy should be compact and confident
- nav and metadata should remain clear without flattening personality

## Layout Direction

### Core principle
Use editorial rhythm instead of repeated app-like modules.

### Practical meaning
- vary section density
- mix full-bleed moments with tighter content blocks
- avoid identical card stacks across every page
- create stronger contrast between lead content and supporting content

### Keep
- clean scanning
- obvious CTA paths
- mobile clarity

### Add
- more asymmetry where it helps
- occasional collage or layered framing
- more intentional quiet space between major content blocks

## Motion Direction
- keep motion sparse
- prioritize atmosphere over novelty
- use reveal and transition effects only where they support hierarchy
- respect reduced-motion preferences

The site should feel alive, not animated for its own sake.

## Photography And Art Direction

### Prioritize
- live venue photos
- rehearsal and session details
- candid member moments
- backstage textures
- posters, gear, cases, and room ephemera

### Use carefully
- grain
- layered edges
- scrapbook or collage gestures
- handwritten or flyer-inspired supporting motifs

### Avoid
- fake vintage overlays with no reason
- clutter that competes with the band
- over-retouched merch or promo imagery

## Interface Guidelines

### Buttons
Avoid making every CTA a rounded pill.

Explore:
- sharper or more varied button shapes
- text-link CTAs where appropriate
- stronger distinction between primary and secondary actions

### Cards
Not every piece of content should be presented as the same card species.

Prefer:
- a mix of image-led, text-led, and hybrid modules
- variation between featured and supporting items
- page-specific composition

### Navigation
Navigation should stay simple, but feel more integrated into the brand system.

Possible directions:
- tighter typographic treatment
- less generic shell feel
- more deliberate active-state behavior

## Responsive Principles
- preserve easy mobile scanning
- let mobile layouts feel designed, not just collapsed
- avoid turning every desktop editorial move into a fragile mobile compromise

## Visual Review Checklist
Before approving any V2 design direction, ask:
- Does this feel like Thrifted Tease or like a premium site kit?
- Does the page still scan clearly on mobile?
- Are the most important actions still obvious?
- Is the visual personality coming from real assets and strong typography rather than decoration alone?
