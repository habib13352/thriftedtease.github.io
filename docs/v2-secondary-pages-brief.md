# Thrifted Tease V2 Secondary Pages Brief

## Purpose
This document defines the V2 direction for the media, shows, merch, and supporting shell elements outside the homepage.

## Media

### Current strength
This is already the site's strongest proof-of-band page.

### V2 job
Make the media page the authenticity anchor for the whole site.

### What to preserve
- venue-based structure
- real photography
- mixed image and video content
- long-scroll archive energy

### What to improve
- stronger intro copy
- more selective curation
- less repeated module rhythm
- captions with more mood and less explanation

### V2 success condition
The page should feel like an archive with taste, not a cleanly organized folder browser.

## Shows

### Current strength
The page is readable and already avoids fake-tour energy.

### V2 job
Support both fan attendance and promoter trust.

### What to preserve
- strong date readability
- clear venue and action hierarchy
- local credibility framing

### What to improve
- make listings feel more real and current
- add recent venue credibility if the active calendar is light
- make the page feel alive instead of representative

### V2 success condition
The page should communicate momentum even when there are not many dates posted.

## Merch

### Current strength
The page is organized and easy to scan.

### V2 job
Make merch feel like part of the band's world.

### What to preserve
- simple grid logic
- direct Shopify path
- tight scope

### What to improve
- replace placeholder-adjacent visual framing
- introduce stronger drop or item identity
- use more convincing imagery or presentation
- make the writing more tactile and less system-oriented

### V2 success condition
The page should feel like a band merch page, not a demo storefront.

## Navigation, Contact, And Footer

### Current strength
These elements are clear and dependable.

### V2 job
Keep them clear while making them feel less like a generic shell.

### What to improve
- tighter labeling
- more branded typography and spacing
- less repeated treatment between every page
- better integration of contact and booking paths

### V2 success condition
The shell should support identity instead of flattening it.

## Shared Secondary-Page Rules
- each page should have a distinct mood and role
- pages should feel related, not identical
- copy should express the band, not explain the page layout
- page intros should be concise and deliberate
