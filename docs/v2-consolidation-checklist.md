# Thrifted Tease V2 Consolidation Checklist

## Direction Already Agreed

- [x] Keep the site static, lightweight, responsive, and easy to maintain.
- [x] Use "thrift-store glamour with live-room credibility" as the brand lane.
- [x] Treat the media archive and real venue photography as the authenticity anchor.
- [x] Prioritize identity first, discovery second, and conversion third.
- [x] Keep the current core pages: Home, Media, Shows, Merch, and contact pathways.

## 1. Lock The Creative System

- [ ] Finalize the brand statement, voice, palette, and typography pairing.
- [ ] Define primary and secondary CTA styles.
- [ ] Replace generic template language with concise copy in the band's voice.
- [ ] Select the strongest live, portrait, behind-the-scenes, and hero images.

## 2. Redesign The Homepage First

- [ ] Approve the homepage content order and CTA hierarchy.
- [ ] Rewrite the hero and short band statement.
- [ ] Add featured music, an upcoming-show signal, featured merch, and curated media.
- [ ] Make the homepage the visual reference for the rest of V2.

## 3. Align The Secondary Pages

- [ ] Media: curate the strongest venue content and improve captions.
- [ ] Shows: use real dates, venue credibility, an honest empty state, and booking contact.
- [ ] Merch: replace placeholder visuals and copy with real products and direct purchase paths.
- [ ] Navigation/footer: keep them clear while bringing them into the V2 brand system.

## 4. Content And Technical Finish

- [ ] Update page titles, meta descriptions, social images, and meaningful alt text.
- [ ] Verify keyboard access, focus states, contrast, semantic structure, and reduced motion.
- [ ] Test every page on mobile and desktop.
- [ ] Keep large images and video out of the critical loading path.
- [ ] Regenerate optimized media whenever source assets change.

## V2 Is Done When

- [ ] The site feels unmistakably like Thrifted Tease, not a generic band template.
- [ ] Visitors understand the band's mood and main actions within seconds.
- [ ] Music, shows, merch, media, and contact information are easy to find.
- [ ] Shows and merch contain real, current content rather than placeholders.
- [ ] The finished site remains accessible, fast, responsive, and maintainable.
