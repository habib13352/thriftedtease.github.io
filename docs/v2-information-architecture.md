# Thrifted Tease V2 Information Architecture

## Purpose
This document defines the recommended content structure, page priorities, and navigation logic for V2.

## IA Goal
Make the site feel more specific without making it more complicated.

The current page set is already appropriate:
- Home
- Media
- Shows
- Merch
- Contact pathways

V2 should improve page purpose and sequencing more than it expands page count.

## Recommended Primary Navigation
- Home
- Media
- Shows
- Merch
- Listen
- Contact

This is close to the current navigation and should likely remain so unless the homepage absorbs "Listen" more fully and reduces the need for a nav-level anchor.

## Recommended Page Roles

### Home
Role:
The emotional front door and main router.

Success condition:
The user understands the band's world quickly and can move to music, shows, merch, or deeper media without friction.

### Media
Role:
Authenticity proof and visual anchor of the brand.

Success condition:
The page feels curated, memorable, and grounded in real rooms.

### Shows
Role:
Live credibility page for both fans and promoters.

Success condition:
The page proves activity and makes next actions obvious.

### Merch
Role:
Band-world extension and conversion page.

Success condition:
The page makes merch feel desirable and connected to the identity of the band.

## Homepage Recommended Order
Suggested structure:
1. Hero
2. Featured music or latest release
3. Short band statement
4. Upcoming show highlight
5. Featured merch item or drop
6. Curated media strip
7. Contact and social footer

Rationale:
- lead with identity
- support discovery early
- introduce proof of activity
- let conversion opportunities come after the visitor already understands the vibe

## Media Page Recommended Structure
1. Intro statement
2. Best recent or most defining venue section first
3. Additional venue and session sections
4. Selected embedded video moments
5. Optional archive continuation or deeper folders if needed later

Rationale:
- the page should feel curated first, archival second

## Shows Page Recommended Structure
1. Live-focused intro
2. Upcoming dates
3. Recent venue credibility or notable rooms
4. Booking/contact pathway
5. Empty-state handling if no active dates

Rationale:
- the page should still sell credibility even during lighter calendar periods

## Merch Page Recommended Structure
1. Merch intro tied to band mood
2. Featured drop or featured items
3. Product modules with clearer story and hierarchy
4. Shopify CTA

Rationale:
- the page should not feel like a detached store shortcut

## Content Hierarchy Rules
- identity comes before explanation
- proof comes before polish
- clear next actions should always be available
- repetitive metadata should be trimmed unless it adds trust or context

## Potential V2 Structural Additions
These are optional, not required:
- a featured release block on the homepage
- a recent venues or "played recently" band on shows
- a lightweight press or booking note if promoter trust becomes a bigger goal

## Structural Additions To Avoid For Now
- adding many new top-level pages
- introducing a blog unless there is a real publishing habit behind it
- turning the site into an archive maze
- adding a framework just to enable more content surfaces

## IA Review Checklist
- Can a first-time visitor understand the band's vibe within seconds?
- Can a fan find music, shows, merch, or contact quickly?
- Does each page have a distinct job?
- Is the media page still the authenticity anchor?
